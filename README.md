# Leone Consulting

Sito web ufficiale di Leone Consulting - AI Engineering, Sviluppo Software e Consulenza IT.

## 🚀 Tecnologie

- **Astro** - Framework web moderno e performante
- **TailwindCSS** - Utility-first CSS framework
- **TypeScript** - Type-safe development

## 📦 Comandi

| Comando                | Azione                                         |
| :--------------------- | :--------------------------------------------- |
| `npm install`          | Installa le dipendenze                         |
| `npm run dev`          | Avvia il dev server su `localhost:4321`        |
| `npm run build`        | Compila il sito per la produzione in `./dist/` |
| `npm run preview`      | Anteprima della build locale                   |
